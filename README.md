# The Day in One Picture — Monday 23 November 2026

A single 1024x1024 front page that sums up Monday 23 November 2026's world
news, drawn procedurally by a Node 22 program (`main.ts`, standard library
only): a 5x7 bitmap-font broadsheet with a lead story, five panels and a
ticker, rendered deterministically to a PNG.

The day's stories: Ukraine sinks the Russian corvette Merkury in Benghazi
(Zelenskyy confirms it Monday); NATO's council meets in emergency session
over the missiles that fell in Poland; Nvidia reinstates Jensen Huang as
CEO; Seoul's Kospi closes at a 10-month low as Asia's AI rout deepens;
the fallout from COP31's collapse; and Belgium's national strike closes
its airspace.
